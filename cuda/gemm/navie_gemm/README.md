# v0：Naive GEMM

## 本版做了什么

FP32 行主序矩阵乘法 `C[M×N] = A[M×K] × B[K×N]`。每个 CUDA 线程负责一个 `C[row, col]`，沿 `K` 方向累加；本版不使用 Shared Memory 分块。当前练习尺寸为 `M=N=K=1024`，线程块为 `16×16`。
